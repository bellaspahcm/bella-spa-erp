3 Lệnh SQL Đối Soát Cơ Sở Dữ Liệu Tự Động

Chạy trực tiếp trên Supabase SQL Editor để nhanh chóng phát hiện lệch số liệu:

1. Đối soát số phát sinh Nợ - Có (Bút toán kép kế toán bắt buộc cân đối = 0)

SELECT 
  journal_entry_id,
  SUM(debit) as total_debit,
  SUM(credit) as total_credit,
  (SUM(debit) - SUM(credit)) as variance
FROM accounting_journal_entries
GROUP BY journal_entry_id
HAVING SUM(debit) != SUM(credit);
-- NẾU TRẢ VỀ BẤT KỲ DÒNG NÀO -> HỆ THỐNG ĐANG BỊ LỆCH SỔ SÁCH KẾ TOÁN (BUG)!

2. Đối soát Doanh thu đã kết chuyển (TK 3387 $\rightarrow$ TK 511) theo tiến độ thẻ liệu trình

SELECT 
  b.id as booking_id,
  b.package_name,
  b.completed_sessions,
  b.total_sessions,
  (b.full_price * (1 - COALESCE(b.discount_percent, 0)/100.0) / b.total_sessions * b.completed_sessions) as expected_realized_revenue,
  (SELECT COALESCE(SUM(debit), 0) FROM accounting_journal_entries WHERE description LIKE '%' || b.booking_number || '%' AND account_code = '3387') as total_realized_accounting
FROM bookings b
WHERE b.completed_sessions > 0;
-- Cột 'expected_realized_revenue' và 'total_realized_accounting' bắt buộc phải trùng khớp từng đồng!

3. Đối soát Tồn kho vật tư và lịch sử Nhật ký biến động kho hàng

SELECT 
  i.id as item_id,
  i.sku,
  i.name,
  i.stock_level as current_stock,
  COALESCE(SUM(l.change_amount), 0) as log_stock_sum
FROM inventory_items i
LEFT JOIN inventory_logs l ON i.id = l.item_id
GROUP BY i.id, i.sku, i.name, i.stock_level
HAVING i.stock_level != COALESCE(SUM(l.change_amount), 0);
-- NẾU CÓ DÒNG TRẢ VỀ -> TỒN KHO THỰC TẾ VÀ NHẬT KÝ KHO ĐANG BỊ LỆCH (BUG)!

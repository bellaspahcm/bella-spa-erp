🔴 Điểm yếu NGHIÊM TRỌNG

⚠️ Lỗ hổng #1: Hardcoded tenant_id fallback
Giá trị tenant_id mặc định xuất hiện >15 lần trong code. Nếu session expire → user có thể truy cập/ghi data vào tenant khác. CẦN FIX NGAY trước khi thương mại hóa.
Vấn đềMức độChi tiết
Hardcoded tenant fallback 🔴 Cực kỳ nguy hiểm Nếu session expire → data ghi vào tenant mặc định thay vì báo lỗi
Dev mock user bypass 🔴 Rủi ro cao Mock admin qua cookie trong dev mode. NODE_ENV sai → bypass toàn bộ auth
Không có CSRF protection 🟡 Trung bình API webhooks cần thêm token verification

Zalo credentials plaintext 🟡 Trung bình zalo_secret_key lưu plaintext trong DB. Nên encrypt hoặc dùng secret manager

💡 Tính năng nổi bật (Unique Selling Points)

🔌 Offline-First Architecture

Dexie.js IndexedDB queue. KTV check-in/out khi mất mạng, tự sync khi online. Không PM spa VN nào có.

💬 Zalo ZNS Real API

Tích hợp Zalo OA thực tế, tự động nhắc lịch 2.5h trước, gửi voucher sinh nhật. Token auto-refresh.

💰 Salary Calculation Engine

Pro-rata deduction: nghỉ phép → trừ ngày, KPI achievement rate, service %. Phức tạp ngang ERP lớn.

📦 Auto-Inventory Consumption

KTV hoàn thành buổi → tự động trừ vật tư theo package_materials mapping. Không cần nhập tay.

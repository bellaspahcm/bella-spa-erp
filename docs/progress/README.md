## 🚨 Rules for AI Agents

### ✅ MUST DO
1. **Read `CURRENT_STATUS.md` FIRST** before any recommendation
2. **Check `NEXT_PRIORITIES.md`** to align with strategic direction
3. **Update progress files** after completing any task
4. **Cross-reference** multiple files for consistency

### ❌ NEVER DO
1. **Never recommend** work that's already complete
2. **Never skip reading** progress files to save time
3. **Never assume** status based on outdated information
4. **Never make up** completion percentages

### 📝 Update Protocol
When you complete a task:
1. Update `CURRENT_STATUS.md` → Move from "In Progress" to "Completed"
2. Update specific progress file (e.g., `DECISION_ENGINE_PROGRESS.md`)
3. Update `NEXT_PRIORITIES.md` if priorities changed
4. Add completion date and summary

## 📊 Progress Tracking Principles

### 1. Single Source of Truth
- If progress files conflict with other docs → Progress files win
- Always update progress files when status changes
- Other docs are reference, progress files are authority

### 2. Honest Status Reporting
- "In Progress" = actively worked on in last 7 days
- "Blocked" = cannot proceed without external input
- "Complete" = delivered, tested, deployed (or deployable)
- "Deferred" = consciously postponed with reason

### 3. Forward-Looking
- Always include "Next Steps" in each file
- Link dependencies explicitly
- Estimate timelines realistically

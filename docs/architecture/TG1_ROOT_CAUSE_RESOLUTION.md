# TG-1 Root Cause Resolution

**Date:** 2026-09-07  
**Status:** 🔒 RESOLVED

---

## Problem Statement

TG-1 Schema-Type Synchronization Gate implementation exhibited **false positive behavior**:

```text
Schema unchanged
Types regenerated
        ↓
Gate BLOCKS (should PASS)
        ↓
FALSE POSITIVE
```

**Symptom:**
- Fresh generation: 2,012,598 bytes normalized
- Committed types: 975,297 bytes normalized
- Same line count (31,000 lines) but vastly different byte sizes
- Test showed: Generate A == Generate B (deterministic)
- Yet: Fresh != Committed (unexpected)

---

## Investigation Trail

### Hypothesis 1: Normalization Function Bug
**Test:** Direct normalization of identical raw files  
**Result:** Normalization worked correctly on identical inputs  
**Conclusion:** REJECTED

### Hypothesis 2: File Encoding Issue
**Test:** Byte-level inspection of raw files  
**Finding:**
```text
Committed:  1,006,296 bytes (raw)
Fresh temp: 2,012,594 bytes (raw)
```

**Analysis:** Temp file generated by TG-1 was DOUBLE the size before normalization

### Root Cause: PowerShell UTF-16 Encoding

**PowerShell redirection behavior on Windows:**
```powershell
command > file.txt
```

**Defaults to UTF-16 encoding**, where each ASCII character becomes 2 bytes with null padding:

```text
"export" →  e x p o r t
           (UTF-16)
```

**Evidence:**
- Raw inspection showed spaced characters (UTF-16 signature)
- Explains exact 2x file size ratio
- Node.js `fs.readFileSync(..., 'utf-8')` reads UTF-16 file, interprets as UTF-8, produces corrupted/doubled content

---

## Solution

### Before (BROKEN):
```typescript
const tempFile = '.tmp-db-types.ts';
const command = 'npx supabase gen types typescript --linked 2>$null > "${tempFile}"';

execSync(command, {
  encoding: 'utf-8',
  shell: 'powershell.exe'
});

const content = fs.readFileSync(tempFile, 'utf-8'); // Reads UTF-16 as UTF-8!
```

**Issue:** PowerShell `>` creates UTF-16 file, Node reads as UTF-8 → garbage

### After (FIXED):
```typescript
const command = 'npx supabase gen types typescript --linked 2>$null';

const content = execSync(command, {
  encoding: 'utf-8',          // Capture stdout directly as UTF-8
  shell: 'powershell.exe',
  maxBuffer: 10 * 1024 * 1024 // 10MB buffer for large files
});
```

**Fix:** Capture stdout directly (no file redirection), Node handles encoding correctly

## Key Learning

> **Platform-specific encoding defaults can break contract assumptions.**

**Contract assumed:** File generation produces UTF-8 content  
**Reality (Windows):** PowerShell `>` produces UTF-16 by default  
**Impact:** 100% false positive rate on healthy state

**Prevention:** Avoid file I/O for cross-platform scripts when stdout capture suffices

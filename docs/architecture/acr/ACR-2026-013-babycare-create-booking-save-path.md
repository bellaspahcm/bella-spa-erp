## Summary

This ACR approves the two Core order files required by PR #191. The approved change removes one proven redundant DB round trip from the BabyCare Create Booking new-customer save path.

---

## Reason For Change

Read-only save-path investigation and proof/staging trace showed that the Create Booking new-customer path immediately queried pending bookings for a customer id generated by the preceding customer insert in the same request.

That lookup was redundant for newly-created customers and measured at 103.61 ms in the action-equivalent trace.

---

## Explicit Non-Goals

- No audit change.
- No outbox change.
- No transaction rewrite.
- No revalidation change.
- No schema or migration change.
- No parallelization.
- No BabyCare production mutation.
- No Healthcare, Education, or Logistics kernel change.

---

## Approved Runtime Shape

```text
createCustomerForBookingIfNeeded
  returns { customerId, created }

createBooking
  if customerResult.created:
    existingBooking = null
  else:
    existingBooking = await findPendingBookingForCustomer(...)
```

Existing-customer behavior remains unchanged.

## Factory Defects Discovered

### Defect #1: Prefix Discovery Collision (CRITICAL)

**Symptom:**
```
Industry scope: "retail"
Expected prefix: "retail_"
Factory discovered: "re"
Result: Matched Real Estate tables instead
```

**Root Cause:** `discoverPrefixFromMigrations()` uses shortest prefix match strategy.

**Evidence:**
```typescript
// scripts/governance/evidence-collector.ts
function discoverPrefixFromMigrations(industryScope: string, migrationsPath: string): string | null {
  // Tries to find shortest prefix that matches industry name
  // "retail" → tries "re" first → matches "re_*" (Real Estate)
}
```

**Impact:** Factory cannot distinguish between industries with overlapping prefix patterns.

**Known collisions:**
- `retail` vs `real-estate` (both match `re`)
- Potential: `auto` vs `automotive`
- Potential: `fin` vs `finance`

**Classification:** GENERIC DISCOVERY DEFECT (affects E9.1)

---

### Defect #2: Type Generation Dependency (BLOCKING)

**Symptom:** Factory pipeline requires local Supabase DB running.

**Evidence:**
```
npx supabase gen types typescript --local
→ docker: command not found
→ Factory evidence collection FAILED
```

**Root Cause:** Type generation hardcoded to require Docker + running local DB.

**Impact:** Factory cannot execute without external infrastructure.

**Classification:** OPERATIONAL DEFECT (affects deployment environments)

---

### Defect #3: No Fallback for Missing DB

**Symptom:** When type generation fails, Factory has no alternative path.

**Evidence:** Factory script exited after type generation failure. No attempt to:
- Parse schema directly
- Generate types from migration SQL
- Proceed with schema-only evidence

**Impact:** Blocks Factory execution in CI/CD or non-Docker environments.

**Classification:** RESILIENCE DEFECT

## Remediation Priorities

### Priority 1: Prefix Discovery Defect (CRITICAL)

**Current behavior:**
```typescript
industryScope "retail" → tries "re" → matches "re_blocks" (Real Estate)
```

**Required behavior:**
```typescript
industryScope "retail" → tries full match first → "retail_" → finds retail_products
```

**Fix location:** `scripts/governance/evidence-collector.ts::discoverPrefixFromMigrations()`

**Strategy:** 
- Try exact industry scope as prefix first: `{scope}_`
- Fall back to progressive shortening only if exact match fails
- Document known collisions

### Priority 2: Type Generation Resilience

**Current:** Hardcoded `npx supabase gen types --local` (requires Docker)

**Required:** Fallback chain:
1. Try Supabase type generation (if DB available)
2. Parse migration SQL directly (if DB unavailable)
3. Use existing types (if present)

**Fix location:** Evidence collector + type generation step

### Priority 3: Missing Implementation (NOT Factory defect)

Sale, SaleItem, InventoryMovement domains NOT Factory bugs — these are expected manual work when E10.2 RECONSTRUCT deferred.

**No remediation needed** (working as designed).

Architecture

  • Core Layer (Frozen Platform Core):** Hạ tầng lõi bất biến, cung cấp các engine nền tảng như Event Bus, State Machine, Policy Engine.

Cách ly Tenant Tuyệt đối & RLS Database

Đảm bảo an toàn bảo mật cấp cao cho 10,000+ doanh nghiệp trên cùng cơ sở dữ liệu.

Security
  • Row-Level Security (RLS) bắt buộc: Thiết lập chính sách bảo mật trực tiếp trên các bảng PostgreSQL. Client không thể đọc dữ liệu chéo của tenant khác.
  • Middleware Token Memoization: Next.js Serverless Middleware tự động phân tách JWT Bearer token và chèn vào client DB để kích hoạt RLS đúng đắn.
  • Kiểm thử bảo mật tự động: CI chạy test kiểm tra ranh giới cách ly tenant cho mỗi Pull Request, cam kết **0 P0 violations**.
PostgreSQL RLS Architecture

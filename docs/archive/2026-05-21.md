## 🧠 Improvements & Learnings

📌 **New Rules / Discoveries**
- Để tránh lỗi vòng lặp đệ quy RLS (Infinite Recursion Loop) cực kỳ phổ biến trong PostgreSQL khi các bảng tự truy vấn chính mình để kiểm duyệt quyền, cách tối ưu nhất là đóng gói các logic truy xuất quyền thông qua các hàm có cờ `SECURITY DEFINER` trung gian (các hàm này sẽ chạy dưới quyền admin mà không áp dụng RLS).
- Khi chạy lệnh node/npm trên môi trường Windows PowerShell, có thể gặp lỗi về Execution Policy chặn load các file `.ps1` (như `npm.ps1`). Giải pháp thay thế đáng tin cậy là chạy trực tiếp thông qua đuôi mở rộng `.cmd` (ví dụ: `npm.cmd run test`, `npm.cmd run build`).

🔄 **Optimizations & Reflections**
- Việc triển khai rate limiting nên đi kèm với cấu trúc `try/catch` an toàn tuyệt đối bao quanh các phương thức phân tích header và Map, đảm bảo trong trường hợp môi trường hosting serverless có thay đổi hoặc runtime lỗi, trải nghiệm đặt lịch của khách hàng thực vẫn không bị ảnh hưởng.

Core của Bella Spa ERP đã được tách thành các primitives tái sử dụng: (1) Booking Engine với State Machine, (2) Session/Service Tracking, (3) Inventory Management, (4) Salary Engine với package multipliers, (5) Multi-tenant RLS với Subscription Quota, (6) Accounting TT133 chuẩn. Các từ khoá nghiệp vụ spa (tên mẹ, tên bé) chỉ là nullable UI labels trong schema — không ảnh hưởng logic lõi. Để chạy cho ngành khác, bạn chỉ cần thay đổi: package names, service categories, và một vài label UI.

Squash Migrations
Dự án có quá nhiều file migration nhỏ. Cần squash các migrations cũ về một file baseline để giảm thời gian chạy migrations và hạn chế lỗi đồng bộ khi setup tenant tự phục vụ mới.

Test Coverage cho Export Actions
File export-actions.ts (19KB, 4 loại report: salary/session matrix/accounting TT133/cash flow) chưa có bất kỳ test case nào. Đây là điểm mù lớn vì export báo cáo tài chính là thao tác quan trọng với kế toán và chủ spa.
🔴 Cao — Thực hiện ngay
Chia nhỏ page.tsx files lớn
app/page.tsx (~52KB) và portal page.tsx (~79KB) cần được tách theo pattern đã áp dụng cho booking/inventory. File quá lớn làm chậm CI build và khó review/test từng feature độc lập.
🔴 Cao — Thực hiện ngay
Thêm npm audit vào CI Pipeline
Hiện tại có K6 load tests và Playwright E2E nhưng chưa có dependency vulnerability scanning trong CI. Thêm npm audit --audit-level=high vào GitHub Actions để tự động phát hiện CVE trong dependencies.
🟡 Trung bình — Q3/2026
Web Push Notifications
Tích hợp Push API hoặc FCM để KTV nhận được thông báo khi app đóng. Sentry đã có (capture lỗi), Telegram bot đã có (AI alerts) — bước tiếp theo là push notification trực tiếp tới KTV/khách hàng.
🟡 Trung bình — Q3/2026
API Documentation (OpenAPI)
Tạo OpenAPI/Swagger spec cho các endpoints AI và webhook. Cần thiết khi mở rộng tích hợp với đối tác hoặc thuê thêm developer mới vào team.
🟡 Trung bình — Q3/2026
CI/CD Security Scanning
Thêm npm audit, Snyk hoặc Dependabot vào GitHub Actions để tự động quét dependency vulnerabilities. Giảm rủi ro supply-chain attack.
🔵 Thấp — Q4/2026
Scheduled Email Reports
Thêm cron job gửi báo cáo P&L tháng qua email cho owner mỗi đầu tháng. Tận dụng cron infrastructure hiện có, chỉ cần thêm email template và SMTP config.
🔵 Thấp — Q4/2026
Biometric Auth cho KTV
WebAuthn/Face ID cho KTV dashboard trên mobile — giảm friction khi check-in, tăng bảo mật. Supabase đã hỗ trợ PKCE flow, chỉ cần thêm WebAuthn layer.
🔵 Thấp — Q4/2026
Tách lớp để hỗ trợ đa ngành
Tạo "industry config" layer tập trung: service_type labels, booking entity names, package terminology. Cho phép deploy cùng codebase cho Home Care, Massage, Pet Care với config khác nhau.
🔵 Thấp — Q4/2026
Native Mobile App (React Native/Expo)
Phát triển ứng dụng native bằng React Native / Expo cho KTV check-in/out địa điểm với định vị GPS chính xác hơn và hỗ trợ chụp ảnh báo cáo liệu trình nhanh chóng.

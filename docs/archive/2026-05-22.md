## 🧠 Improvements & Learnings

📌 **New Rules / Discoveries**
* **Trình bao bọc CMD trên Windows**: Khi chạy `npm` hoặc các lệnh Node CLI trong Windows PowerShell mà gặp lỗi ExecutionPolicy, việc gọi `npm.cmd` trực tiếp hoặc sử dụng UTF-8 qua `$env:PYTHONIOENCODING='utf-8'` giúp khắc phục triệt để vấn đề phân giải và lỗi hiển thị ký tự đặc biệt.
* **Tự động khởi tạo kho chi nhánh nhận**: Mô hình tự động tạo bản ghi vật tư mới ở chi nhánh con khi xác nhận nhận hàng giúp loại bỏ thao tác thủ công, tránh chênh lệch mã hàng.

🔄 **Optimizations & Reflections**
* **Next.js Server Actions Mocking**: Trong Next.js Server Components, mock server actions ở Jest đôi lúc dính lỗi hoisting TDZ. Việc đưa mock proxy lên đối tượng toàn cục `global.mock` là giải pháp hữu hiệu vượt qua rào cản này.
* **Framer Motion Custom Guides**: Thay vì dùng các thư viện cồng kềnh như `react-joyride` làm phình dung lượng bundle và gây lỗi hydration Next.js, tự thiết kế backdrop Blur + Framer Motion nhẹ nhàng hơn, vừa tùy biến sâu sắc theme thương hiệu vừa đảm bảo zero warning.

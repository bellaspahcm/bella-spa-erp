# docs/archive/operational — Operational Archive

**Moved:** 2026-08-23 (Phase 3 reorganization)  
**Reason:** Root folder cleanup — operational artifacts không còn là reference tài liệu hiện tại.

## Nội dung thư mục này

Đây là các file **đã hoàn thành vai trò** và không cần đọc trong workflow hàng ngày:

| Nhóm | Mẫu filename | Loại |
|---|---|---|
| Session logs | `DAY_X_*.md`, `WEEK_X_*.md` | Daily/weekly progress notes |
| Deploy artifacts | `DEPLOY_*.md`, `DEPLOYMENT_*.md`, `QUICK_DEPLOY.md` | One-time deployment instructions |
| Feature fix reports | `REACT_*.md`, `KTV_DASHBOARD_*.md`, `*_FIX_*.md` | Post-fix summaries |
| Status snapshots | `*_READY.md`, `*_COMPLETE.md`, `DONE.md` | Point-in-time status snapshots |
| Troubleshooting notes | `REDIS_CACHE_*.md`, `THEMING_*.md`, `STEP_BY_STEP_*.md` | One-off debug guides |
| Implementation summaries | `*_IMPLEMENTATION_*.md`, `*_STATUS_SUMMARY.md` | Sprint implementation notes |

## Cần tìm lại?

File archive **không bị xóa** — vẫn đầy đủ nội dung. Dùng khi cần:
- Debug lịch sử ("ngày đó đã làm gì?")
- Tái hiện quyết định cũ
- Audit trail

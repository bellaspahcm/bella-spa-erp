ARCHITECTURAL DECISIONS
-----------------------
1. Query-based lineage (not Graph DB)
   - Rationale: Simplicity, testability, no external deps
   - Note: Production-scale performance deferred

2. No repository pattern in E7.3
   - Rationale: Clear separation, easier testing
   - Operations receive data as parameters

3. Compliance as evidence aggregator
   - Rationale: Compliance ≠ Decision
   - E7.3 says "VIOLATION" but NOT "QUARANTINE"

4. Explicit evaluation date
   - Rationale: Determinism, reproducibility
   - No hidden clock inside rules

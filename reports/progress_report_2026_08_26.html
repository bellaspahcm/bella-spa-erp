Chất lượng Phân tầng kiểm thử & Sanity Pipeline
Tầng kiểm thử Công cụ sử dụng Mục tiêu kiểm chứng Lệnh thực thi (NPM Script) Trạng thái
L1: Static Linting ESLint Phát hiện lỗi cú pháp tĩnh, chuẩn hóa conventions và chất lượng viết mã nguồn. npm run lint / lint:strict ✓ Active
L2: Compilation Safety TypeScript Compiler (TSC) Xác thực chặt chẽ kiểu dữ liệu (type safety) toàn monorepo trước khi đóng gói. npm run build ✓ Active
L3: Unit Testing Jest / Vitest (3a) Kiểm thử cô lập logic nghiệp vụ thuần túy, helpers, và validators. npm run test:unit / test:runtime:3a ✓ Active
L4: Integration Testing Jest / Vitest (3b) Kiểm thử liên phân hệ giữa các OS (Healthcare, Logistics, Finance) với Mock Database. npm run test:integration / test:runtime:3b ✓ Active
L5: Smoke Testing / Sanity Node.js scripts / Playwright Kiểm tra nhanh kết nối cơ sở dữ liệu, quyền RPC, happy paths sau deploy. npm run health:check / db:rpc-smoke:check ✓ Active
L6: End-to-End (E2E) Testing Playwright Kiểm thử toàn trình trải nghiệm người dùng thực và kiểm chứng cô lập Tenant Isolation. npm run e2e / e2e:tenant-isolation ✓ Active
L7: Performance & Load K6 Giả lập tải trọng cao (stress test, load test) đo lường độ trễ và giới hạn chịu tải API. npm run load:smoke ✓ Active
